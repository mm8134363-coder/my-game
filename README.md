# صوتنا — تطبيق ترفيه ودردشة صوتية + لوحة تحكم
تشغيل:
1. ثبّت Node.js.
2. داخل المجلد نفّذ: npm install
3. شغّل: npm start
4. التطبيق: http://localhost:3000
5. لوحة التحكم: http://localhost:3000/admin
6. مفتاح المدير الافتراضي: admin123

مهم: GitHub Pages يستضيف الواجهة الثابتة فقط، ولا يشغّل Node/WebSocket. لذلك الخادم يجب أن يعمل على استضافة تدعم Node.js، ثم تستخدم عنوان WSS الخاص به من الواجهة.

هذه النسخة لا تحفظ البيانات في قاعدة بيانات؛ الغرف والمستخدمون والبلاغات مؤقتة أثناء تشغيل الخادم.
