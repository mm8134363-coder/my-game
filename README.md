# لوحة تحكم صوتنا
لوحة تحكم تجريبية لإدارة تطبيق الدردشة الصوتية والغرف.

تشمل:
- إحصائيات المستخدمين والغرف.
- إنشاء وإغلاق الغرف.
- إدارة المستخدمين والحظر التجريبي.
- مراجعة البلاغات.
- إعدادات التطبيق.

هذه نسخة واجهة أمامية فقط. لربطها بتطبيق حقيقي يلزم Backend وقاعدة بيانات ونظام مصادقة وWebRTC للصوت.
